# Task: 領域知識建置指南 (Domain Creation Guide)

## 用途
當專案需要引入全新的領域知識 (Domain Knowledge) 以供 `@Consultant` 審查計畫時，請依照此格式建立新的 `.md` 檔案至 `.agents/domains/` 目錄。

## 必須包含的章節 (Required Sections)

### 1. 核心投資/業務哲學 (Core Philosophy)
定義該領域的核心價值觀與底層邏輯。條列 3 項最重要的原則 (例如：左側交易的「價值回歸」與「越跌越買」)。

### 2. 戰略審查重點 (Review Guidelines)
明確指示 `@Consultant` 在看草案時要抓哪些蟲。必須包含：
- **【防呆】**：該領域絕對不可觸犯的禁忌 (例如：長線投資嚴禁盲目停損)。
- **【優化】**：該領域常見的最佳實踐建議。
- **【風險】**：該領域特有的風險盲區 (例如：資金耗盡、流動性風險)。

### 3. 衝突仲裁提示 (Conflict Triggers)
這是最重要的一環。必須列出該領域「容易與哪些其他流派打架」，並給出權重或合併的建議。
