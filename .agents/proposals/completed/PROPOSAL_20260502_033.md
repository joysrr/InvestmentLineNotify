## 四、SoT 邊界（ADR-0041 核心）

| 維度       | mempalace（primary）                     | GitNexus（auxiliary cache）                 |
| ---------- | ---------------------------------------- | ------------------------------------------- |
| 層級       | 語意層（decisions / lessons / context）  | 語法層（call graph / impact / AST）         |
| 持久性     | 跨 session（ADR-0039 v2 SoT）            | per-repo `.gitnexus/`（gitignored；可重建） |
| 寫入       | rules 直呼 add_drawer                    | user 自跑 `gitnexus analyze`                |
| Agent 用法 | 派發前必查（既有鐵律）                   | 大型 refactor / cross-file impact 才查      |
| 不可達時   | `.export/` fallback + `.pending/` buffer | 直接退回 grep / Read（無 fallback 必要）    |

**鐵律**：mempalace 永遠是 SoT；GitNexus 結果若要持久 → 寫 mempalace drawer 摘要（user 手動 / agent 提醒）。
