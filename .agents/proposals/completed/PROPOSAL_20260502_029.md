# PROPOSAL_502_029: Scope 判定強化 + Runtime Context + Agent Bootstrap

## 一、背景（User 反饋 2026-05-04）

3 個實機觀察：

1. **Proposal 建立位置錯**：本來該放 `workspaces/<name>/proposals/` 的卻放到 `proposals/` framework 區
2. **環境特殊 setup 沒記**：例如 Windows `$env:Path = "D:\node-v24.12.0-win-x64;..."` 後續 agent 不知道
3. **Qwen 不照流程走**：可能 model 推理力 / 也可能沒 read framework；想要「一次讀完記起來」的單檔指南

## 二、執行 Tasks

### T-1（Issue 1）：Proposal Scope 判定強化

- `rules/retro.md §s07` 補：起草前**第一動作**判 scope（`framework` vs `project:<name>`）
- 加 explicit decision tree：
  ```
  User 指令 / ROUTING_TICKET 提及 workspace name？
    → 是 → scope: project:<name>；存 .agents/workspaces/<name>/proposals/
    → 否 → 影響範圍涉 .agents/rules / decisions / iron-rules / skills（cross-project 共用）？
              → 是 → scope: framework；存 .agents/proposals/
              → 否 → ⚠️ 需 User 確認
  ```
- `rules/lead.md §s_pre_adoption_check` 補：採納前**強制驗證**提案 frontmatter `scope` 與儲存路徑一致
- `skills/templates/rule-update-proposal-{full,lite}-template.md` 加 scope 判定提示

### T-2（Issue 2）：Workspace RUNTIME_CONTEXT 機制

- `WORKSPACE_SCHEMA.yaml` 加新 block `RUNTIME_CONTEXT`：
  ```yaml
  RUNTIME_CONTEXT: # 選填；workspace 特化執行環境
    platform: win32|darwin|linux
    shell: powershell|bash|zsh|cmd
    pre_command_hooks: # 每次執行 shell command 前要先跑的 setup
      - description: "..."
        command: "..."
        shell: powershell|bash
        reason: "..."
    binaries: # 強制路徑
      node: <abs path>
      python: <abs path>
    env_vars: # 環境變數
      KEY: VALUE
  ```
- `agent-driven-onboarding.md` §2 補：onboarding 時偵測 platform / 詢問 binary path
- `rules/lead.md §s05` 派發時：若 active workspace 含 RUNTIME_CONTEXT.pre_command_hooks → 注入 ROUTING_TICKET 提示 sub-agent 執行 shell 前先跑 hooks
- `tasks/session-start-checklist.md` 補：cold-start 讀 workspace 時把 RUNTIME_CONTEXT 一併載入 context

### T-3（Issue 3）：Agent Bootstrap 一次性指南

- 新建 `.agents/AGENT_BOOTSTRAP.md`（**核心檔**；最高優先；agent 進入專案第一個 read）
  - 200-300 行；單檔覆蓋 80% 常見流程
  - 內容章節：
    1. 框架架構速覽（13 rules + iron-themes + ADR + workspace；30 sec 讀完）
    2. Session-start checklist（並行 5 step）
    3. 派發流程（dispatch DSL；ROUTING_TICKET 範本）
    4. Mempalace 操作三件套（search / wake-up / add_drawer）
    5. 「我要做 X 該讀哪份」對照表（指向細節文件）
    6. 撰寫風格鐵律（agent 0 user-script-execution）
- `qwen.md §0` 補：明確指示「Session 第一動作 = Read `.agents/AGENT_BOOTSTRAP.md`」
- 提供 user 可貼至 Qwen 開頭的「強化 prompt」範本（短訊；明確要求 agent 先讀 bootstrap）
