## 三、提案內容

### 3.1 `.claude/settings.json` 配置 hook

使用 Claude Code PreToolUse hook（對齊 Claude Code 官方機制）：

```json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Bash",
        "command": "if echo \"$TOOL_INPUT\" | grep -q 'git commit'; then node .agents/tests/schema-validator.mjs && node .agents/tests/proposal-intent-consistency.mjs; fi"
      }
    ]
  }
}
```

或簡化為 shell script `.agents/tests/run-all.sh`：

```bash
#!/bin/bash
node .agents/tests/schema-validator.mjs || exit 2
node .agents/tests/proposal-intent-consistency.mjs || exit 2
echo "✅ All validation passed"
```

### 3.2 `.claude/settings.local.json` 使用範例

提供 User 參考範本（不強制執行；User 可選擇啟用）：


### 3.3 RULES_DESIGN_GUIDE §十一 擴充

於 §版本遞增時的驗證義務 新增：

```markdown
### 自動化觸發機制（依 PROPOSAL_20260422_019）

配置 `.claude/settings.json` 的 PreToolUse hook：

- 偵測 `git commit` 命令
- 自動執行 `.agents/tests/run-all.sh`
- 退出碼非 0 → Block commit

**選用但強烈建議**：User 可依 `.claude/settings.local.json.example` 複製啟用。
```

### 3.4 新建 `.agents/tests/run-all.sh`

```bash
#!/bin/bash
# Run all validation scripts
# 由 PROPOSAL_20260422_019 建立

set -e

echo "🔍 Running Schema Validator..."
node .agents/tests/schema-validator.mjs
SCHEMA_CODE=$?

echo ""
echo "🔍 Running Proposal Intent Consistency..."
node .agents/tests/proposal-intent-consistency.mjs
INTENT_CODE=$?

echo ""
if [ $SCHEMA_CODE -eq 0 ] && [ $INTENT_CODE -eq 0 ]; then
  echo "✅ All validation passed"
  exit 0
else
  echo "❌ Validation failed (schema=$SCHEMA_CODE, intent=$INTENT_CODE)"
  exit 2
fi
```
