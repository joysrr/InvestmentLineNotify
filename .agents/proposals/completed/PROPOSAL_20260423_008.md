## 一、問題描述

### 1.1 User 檢視結論（2026-04-23）

> 「9 validators 序列執行 → pre-commit 慢」

當前 `run-all.sh` 執行模式：

```
Schema (1 sec) → Intent (1 sec) → Workspace (1 sec) → Drift (10 sec) →
Ref (1 sec) → Sync (1 sec) → Loc (1 sec) → Scripts L1+L3 (15 sec) → Total ~30-45 sec
```

### 1.2 影響評估

| 場景 | 當前體驗 | 目標體驗 |
|-----|---------|---------|
| 修 typo + git commit | 等 ~35 sec | < 10 sec |
| 大型提案執行 + git commit | 等 ~35 sec | 可接受（已是大改動）|
| pre-commit hook 觸發 | ~35 sec | < 10 sec（fast mode）|
| 手動 bash run-all.sh | ~35 sec | 完整模式可接受 |

### 1.3 機械化分析：哪些 validators 可並行

```
依賴分析（依各 validator 檔案讀取 / 改寫範圍）：
  schema-validator (rules/*.md)              ← 只讀；無依賴
  proposal-intent-consistency (proposals/)   ← 只讀；無依賴
  workspace-schema-validator (WORKSPACE_SCHEMA + workspaces/) ← 只讀；無依賴
  agent-drift-simulator (rules/*.md)         ← 只讀；無依賴
  ref-validator (rules + skills frontmatter) ← 只讀；無依賴
  agents-overview-sync-validator (agents-overview.md + multiple) ← 只讀；無依賴
  docs-location-validator (docs/ + .agents/docs/) ← 只讀；無依賴
  scripts/run.sh (含 smoke.test.sh 寫測試 workspace)
    ← 寫入：workspaces/smoke_*（已有 trap cleanup）
    ← 改 CURRENT_WORKSPACE（已有 backup/restore）

結論：
  · 8 validators 完全互不依賴 → 100% 可並行
  · 1 validator (scripts) 寫入 workspaces/smoke_* → 不可與 workspace-schema-validator 同時跑（潛在競爭）
  · 並行策略：先跑 8 個只讀 validators 並行 → 最後序列跑 scripts
```

## 三、提案內容

### 3.1 Part 1：`run-all.sh` 並行執行

#### 1.1 設計

```bash
#!/bin/bash
# run-all.sh — Run all validation scripts (PROPOSAL_20260423_008 並行模式)

set +e
SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"

# -------- Mode detection --------
MODE="${1:-full}"
case "$MODE" in
  full|--full) MODE="full" ;;
  fast|--fast) MODE="fast" ;;
  --regenerate-indexes) MODE="regen"; ;;  # 由 PROPOSAL_007 處理
  --validator) MODE="single"; SINGLE_NAME="${2:-}"; ;;
  *) ;;
esac

# -------- Helper: 並行執行一組 validators --------
# 使用 PIPESTATUS 與背景作業；輸出寫入 /tmp 防混雜
run_parallel_validators() {
  local -a names=("$@")
  local -a pids=()
  local -a logs=()
  local -A exit_codes=()

  for name in "${names[@]}"; do
    local logfile="/tmp/validator-${name}-$$.log"
    logs+=("$logfile")
    case "$name" in
      schema) node "$SCRIPT_DIR/schema-validator.mjs" > "$logfile" 2>&1 & ;;
      intent) node "$SCRIPT_DIR/proposal-intent-consistency.mjs" > "$logfile" 2>&1 & ;;
      workspace) node "$SCRIPT_DIR/workspace-schema-validator.mjs" > "$logfile" 2>&1 & ;;
      drift) node "$SCRIPT_DIR/agent-drift-simulator.mjs" --mode static > "$logfile" 2>&1 & ;;
      ref) node "$SCRIPT_DIR/ref-validator.mjs" > "$logfile" 2>&1 & ;;
      sync) node "$SCRIPT_DIR/agents-overview-sync-validator.mjs" > "$logfile" 2>&1 & ;;
      loc) node "$SCRIPT_DIR/docs-location-validator.mjs" > "$logfile" 2>&1 & ;;
    esac
    pids+=($!)
  done

  for i in "${!pids[@]}"; do
    wait "${pids[$i]}"
    exit_codes["${names[$i]}"]=$?
  done

  # 串聯輸出 + 釋放 logs
  for i in "${!names[@]}"; do
    local name="${names[$i]}"
    local code="${exit_codes[$name]}"
    local logfile="${logs[$i]}"
    echo ""
    echo "🔍 ${name} (exit ${code})"
    cat "$logfile"
    rm -f "$logfile"
  done

  # 回傳：用 echo NAME=CODE 格式（caller 解析）
  for name in "${names[@]}"; do
    echo "RESULT_${name}=${exit_codes[$name]}"
  done
}

# -------- Full mode（並行 8 + 序列 1）--------
if [ "$MODE" = "full" ]; then
  echo "🔍 Running 8 validators in parallel + scripts/ tests..."
  RESULTS=$(run_parallel_validators schema intent workspace drift ref sync loc | tail -8)
  # 解析 RESULT_xxx=N
  eval "$RESULTS"

  echo ""
  echo "🔍 Running scripts/ Tests (serial; PROPOSAL_20260423_006)..."
  bash "$SCRIPT_DIR/scripts/run.sh" >/dev/null 2>&1
  RESULT_scripts=$?
  if [ $RESULT_scripts -eq 0 ]; then
    echo "ℹ️  scripts/ tests: ✅ 全通過（L1 單元 + L3 smoke）"
  else
    echo "⚠️  scripts/ tests: ❌ 部分失敗"
  fi
fi

# -------- Fast mode（依 git diff）--------
if [ "$MODE" = "fast" ]; then
  echo "🔍 Running fast mode (git diff-aware)..."
  source "$SCRIPT_DIR/lib/git-diff-detector.sh"
  RELEVANT=$(detect_relevant_validators)  # 輸出: "schema sync ref"
  echo "ℹ️  Detected relevant validators: $RELEVANT"
  if [ -z "$RELEVANT" ]; then
    echo "✅ No framework changes; skipping all validators"
    exit 0
  fi
  RESULTS=$(run_parallel_validators $RELEVANT | tail -8)
  eval "$RESULTS"
fi

# -------- Single validator mode --------
if [ "$MODE" = "single" ]; then
  if [ -z "$SINGLE_NAME" ]; then
    echo "Usage: bash run-all.sh --validator <schema|intent|workspace|drift|ref|sync|loc|scripts>"
    exit 2
  fi
  run_parallel_validators "$SINGLE_NAME"
  exit 0
fi

# -------- Policy（保留既有判斷）--------
# 簡化展示：每個 RESULT_xxx 解析 + 依既有 policy 決定 exit
# ... 略 ...
```

#### 1.2 並行安全性

- 8 個唯讀 validators 並行：無資源競爭（皆讀檔；不寫框架檔）
- scripts L3 smoke test 寫入 `workspaces/smoke_*` → 必須序列（與 workspace-schema-validator 順序）
- 暫存 log 用 PID 區隔避免並行寫衝突

#### 1.3 預期速度

```
8 並行 validators 瓶頸 = max(各 validator 時間) = drift (~10 sec)
scripts L1+L3 = ~15 sec
總時長 = max(10, 15) ≈ 15 sec（並行段的瓶頸）+ 序列段
       ≈ 25 sec（vs 當前 35 sec；-29%）
```

理論上 scripts 也可改為「先跑 scripts L1（~130 ms）並行 + L3 序列」進一步優化；本提案保守不動。

### 3.2 Part 2：`--fast` 模式（git diff 偵測）

#### 2.1 設計

新建 `.agents/tests/lib/git-diff-detector.sh`：

```bash
#!/bin/bash
# git-diff-detector.sh — 依 git staged 檔案決定相關 validators

detect_relevant_validators() {
  local files
  # 偵測 staged 檔案；若無 staged 則用 working tree changes
  files=$(git diff --cached --name-only 2>/dev/null)
  if [ -z "$files" ]; then
    files=$(git diff --name-only 2>/dev/null)
  fi
  if [ -z "$files" ]; then
    echo "schema intent workspace drift ref sync loc"  # fallback：無變更跑全部
    return
  fi

  local -A needed=()
  while IFS= read -r f; do
    case "$f" in
      .agents/rules/*.md)
        needed[schema]=1; needed[drift]=1; needed[ref]=1; needed[sync]=1
        ;;
      .agents/skills/*.md)
        needed[schema]=1; needed[ref]=1; needed[sync]=1; needed[workspace]=1
        ;;
      .agents/tasks/*.md)
        needed[schema]=1; needed[ref]=1; needed[sync]=1
        ;;
      .agents/tech-stacks/*.md)
        needed[schema]=1; needed[workspace]=1
        ;;
      .agents/proposals/*.md|.agents/proposals/active/*.md|.agents/proposals/completed/*.md)
        needed[intent]=1; needed[sync]=1
        ;;
      .agents/WORKSPACE_SCHEMA.yaml)
        needed[workspace]=1
        ;;
      .agents/scripts/*.mjs)
        needed[scripts]=1
        ;;
      .agents/tests/*.mjs|.agents/tests/scripts/*.mjs)
        needed[scripts]=1
        ;;
      .agents/docs/*.md|docs/*.md)
        needed[loc]=1; needed[sync]=1
        ;;
      .agents/RULES_DESIGN_GUIDE.md)
        needed[drift]=1; needed[sync]=1; needed[ref]=1
        ;;
      .agents/CHANGELOG.md|.agents/FRAMEWORK_VERSION|.agents/RULES_VERSION_INDEX.md)
        needed[sync]=1
        ;;
      .agents/proposals/PROPOSAL_INDEX.md)
        needed[intent]=1
        ;;
    esac
  done <<< "$files"

  # 輸出空格分隔的 validator names
  echo "${!needed[@]}"
}
```

# 手動指定單一
