# PROPOSAL_20260502_002: MemPalace 深度整合（Tier 1）

## 一、背景

PROPOSAL_502_001 完成 MemPalace primary backend；但僅 @Lead 直接使用。12 sub-agents 仍「無記憶」狀態；未發揮 96.6% R@5 retrieval 潛力。

## 二、目標

讓 12 sub-agents（含 5 高優先深度整合 + 7 一般整合）+ 4 關鍵 tasks 全面接入 MemPalace。

## 三、分層整合策略

### 高優先深度整合（5 agents）

| Agent      | 用途                                          | 預期效益                                   |
| ---------- | --------------------------------------------- | ------------------------------------------ |
| @Retro     | wake-up 跨 session 找反覆問題                 | retro.md §s04 歷史比對升級為 vector search |
| @QA        | search debug_graveyard 補 TEST_SPEC           | 既有踩坑自動成 TC                          |
| @Reviewer  | search debug_graveyard anti-pattern checklist | review 標準補強                            |
| @Architect | search architecture 新模組設計前              | 避免重複；確認 ownership                   |
| @Security  | search SC-XX 歷史 incidents                   | 資安歷史脈絡                               |

### 一般整合（7 agents；輕量 1 行入口）

@Backend / @Frontend / @Consultant / @Planner / @Auditor / @Assistant — 各加 §使用 Memory Palace 1-line 入口；指向 `skills/memory-operations.md`。

註：@Lead 已整合（§s_memory_palace v2.0）。@Auditor 暫未整合（原稿誤；2026-05-02 PROPOSAL_502_004 D-1 勘誤）— auditor-rubric-iron Rule #2/#3 限制下，於 PROPOSAL_502_004 D-1 補 read-only `mempalace.search` baseline-search hook（不違反 iron-rule；達成 13/13 整合）。

### Tasks 整合（4 個關鍵 task）

| Task                            | Memory query step                                     |
| ------------------------------- | ----------------------------------------------------- |
| hotfix-checklist                | Step 0 加：`mempalace search <事故關鍵詞>` 找歷史同類 |
