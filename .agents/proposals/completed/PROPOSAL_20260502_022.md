# PROPOSAL_20260502_022: Token 成本優化（3 個高 ROI；Lite tier）

## 一、背景

User 詢問框架對自用企業 LLM 的 token 負擔；2026-05-04 產出 `TOKEN_COST_ANALYSIS_REPORT.md` 識別 3 個高 ROI 優化：

| #   | 優化                                                                | 預期節省             | 工時   |
| --- | ------------------------------------------------------------------- | -------------------- | ------ |
| O-1 | Iron-themes per-agent 載入（補完 4 missing rules + 載入策略文件化） | ~6-8% / dispatch     | 1-2h   |
| O-2 | Skill lazy-load 顯式標註（避免 harness 預載 8K+ 大 skill）          | ~20-30% / cold start | 1h     |
| O-3 | mempalace.search 預設 limit 5 → 3（足夠決策；省 40% 查詢成本）      | ~600-1K / 查詢       | 30 min |

User 採 (A) 立即執行。

## 二、執行 Batches

### Batch 1（O-3）：mempalace.search limit 預設 3

- `skills/memory-operations.md` §2.1 範例 limit=5 → limit=3
- §5 驗證 + §6.2 baseline `--results 5` 改 `--results 3`
- 5 高頻 rules（lead/architect/backend/qa/retro）若有 search 範例，default 改 3

### Batch 2（O-2）：Skill lazy-load 標註

- 新增 schema：skills frontmatter 加 `load_priority: lazy | eager`（default = lazy；只 system-prompt 級為 eager）
- `skills/lead-orchestration-guide.md`（8,280 tokens；最大）標 `load_priority: lazy`
- INSTALL.md 補章節：harness loader 應只在 LLM 主動 Read 時載 lazy skill
- rule 內「完整細則 = `skills/...md`」格式保留（已是 lazy 引用模式）

### Batch 3（O-1）：補完 applies_iron_themes

- 4 missing rules（architect / frontend / planner / retro）frontmatter 加 `applies_iron_themes`
- 文件化「rule loader 應只載 frontmatter applies_iron_themes 列出的鐵律」
- INSTALL.md 補載入策略章節

### T-D 收尾

- proposal active → completed；DONE
- v6.30 → v6.31（patch bump；純優化）
- CHANGELOG [v6.31] 條目

## 五、預期 vs 實際節省

| 項目                      | 預估                | 實際機制                                                                                                         |
| ------------------------- | ------------------- | ---------------------------------------------------------------------------------------------------------------- |
| O-1 iron-themes per-agent | 6-8% / dispatch     | 4 worker/orchestrator rules 明標 `[]`；其他 9 rules 已標明白 1-3 個；harness loader 可依此跳過不相關             |
