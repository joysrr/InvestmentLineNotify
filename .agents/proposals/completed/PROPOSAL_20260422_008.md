## 一、問題描述

**根因分類**：`ARCH`（缺乏系統自管理迴路）

2026-04-22 自我評比報告識別：維度 5.3 LLM-as-a-Judge = **1.0/5**，為全 15 細項最低分。本次評審為**臨時手動執行**，無規則強制「定期由獨立 Judge Agent 執行標準化評分」；系統缺乏自動化閉環，長期健康退化無偵測機制。

## 二、根因分析

- **現況**：`@Retro` 執行「根因分析 + 規則提案」，但不執行「數字化品質評分」

- **對齊標準**：`docs/Reports/AI Agent 品質實踐評鑒表 (2026 旗艦版).md` + `自動化評審手冊 (2026 專業版).md`

```markdown
# Role: AI Agent Quality Auditor

## 任務目標
依 `docs/Reports/AI Agent 品質實踐評鑒表 (2026 旗艦版).md` 與 `自動化評審手冊 (2026 專業版).md` 執行定期 5 維度 × 15 細項評分，產出結構化 AUDIT_REPORT 供 @Retro 參照。

## 觸發條件
- **定期**：每 `AUDIT_INTERVAL` 個工作對話（依 §十四，預設 10）
- **事件**：任一維度分數 < 3.0 時回報 🟡 `AUDIT_QUALITY`
- **手動**：User 明確下達「執行 Agent 品質審計」

## 執行流程
1. 派遣 5 個並行子 Agent（一維度一個）
2. 每個子 Agent 依手冊 §自動化評審提示詞 打分
3. 彙整 JSON + 寫入 AUDIT_HISTORY.md
4. 任一維度 < 3.0 → 透過 @Lead 通知 @Retro 提案改善

## 核心禁止
- **絕對禁止** 越權撰寫改善提案（@Retro 專屬）
- **絕對禁止** 干擾現行 Workflow（純被動評審）
```
