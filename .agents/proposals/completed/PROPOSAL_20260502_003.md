# PROPOSAL_20260502_003: MemPalace 永續性整合（Tier 2+3 精選 4 項）

## 一、目標

採納 PROPOSAL_502_002 後評估 Tier 2/3 永續性 ROI；採納以下 4 項雙星永續性 win：

1. **C-1 Auto mining hook** (Tier 2-1) — 自動採礦；零手工維護
2. **C-2 Compress + count monitor** (Tier 3-4) — 長期 drawer bloat 防護
3. **C-3 Workspace 切換 wake-up** (Tier 2-3) — multi-project UX
4. **C-4 重大 anomaly → drawer** (Tier 2-2 過濾版) — 重大 incident 自動累積

不採納：

- Tier 3-3 self-evolving prompts（anti-sustainability；違反 ADR-0001）
- Tier 3-2 cross-workspace bridge（solo + single workspace 暫無需求）
- Tier 3-1 knowledge graph 全面導入（風險高；只做最小可行 retro 用）

## 三、設計細節

### C-1 Auto mining hook

新建 `.agents/scripts/hooks/mempalace-auto-mine.sh`：

- 偵測 commit 中是否含 `.agents/memory/` 或 `.agents/workspaces/<ws>/memory/` 變動
- 若有 → `mempalace mine <changed-paths>` 增量採礦
- 冪等（mempalace mine 自動跳過已採礦檔案）
- 無變動 → 跳過

User 可選裝至 `.git/hooks/post-commit`（手動 ln -s）或 `.claude/settings.local.json` PostToolUse hook（自動）。

### C-2 Compress + count monitor

memory-palace-validator.mjs 新增：

- 取 `mempalace status` drawer count
- 警示閾值：drawer count > 1000 → 🟡 建議 `mempalace compress`
- 嚴重閾值：drawer count > 5000 → 🔴 必 compress（影響 retrieval 速度）

skills/memory-operations.md 新增 §6 Compress 流程：

- `mempalace compress` 何時呼叫
- AAAK Dialect 30x 壓縮特性
- 壓縮前後驗證

### C-3 Workspace 切換 wake-up

init-workspace.mjs 升級：

- workspace switch / init 完成後自動跑 `mempalace wake-up`
- 顯示 L0+L1 上下文（~600-900 tokens）給 User
- 提示「Memory Palace ready；wake-up 結果已注入」

### C-4 重大 anomaly → drawer

assistant.md §s07（阻斷機制；immutable）擴充：

- 🔴 條件持續 > `PENDING_RED_EXPIRE` (2 工作對話) 未處理
- 自動寫 markdown drawer 至 `.agents/memory/debug_graveyard/DG-YYYYMMDD-NNN-<slug>.md`
- 標 `category: operational_critical` / `severity: critical`
- 觸發 `mempalace mine` 採礦

過濾條件（防噪音）：

- 一般 🟡 警示 → 不寫 drawer
- 🔴 自動關閉（條件消失）→ 不寫
- 只在「持續 🔴 + 跨 N 工作對話」才寫

## 五、執行紀錄

### Phase C-1+C-2（auto-mine hook + compress monitor）

- 新建 `.agents/scripts/hooks/mempalace-auto-mine.sh`（97 行）
  - 偵測 git HEAD commit / staged 變動含 `.agents/memory/*` 或 `.agents/workspaces/<ws>/memory/*`
  - 去重至 room root（避免逐檔多次採礦）
  - 旗標：`--dry-run` / `--staged` / `--quiet` / `--help`
