## Tasks

### F-1 state.py (~250 LOC)

完整 v7.22 schema TypedDict；reducers：`decision_path: append` / `mempalace_writes: union` / `runtime_telemetry: merge_dict`。

### F-2 parser.py (~200 LOC)

讀 `.agents/rules/*.md` + `.agents/skills/*.md` → 抽 frontmatter MACHINE_READABLE 區塊 + 結構化 sections → 形成各 agent system prompt + behavior config (e.g. autonomy default / hotfix tier rules / hybrid classifier layers)。

### F-3 llm_adapter.py (~280 LOC)

LangChain `BaseChatModel` 兼容：

- `sampling` mode: 透過 MCP `sampling/createMessage` 反向呼 harness 視窗 LLM
- `api` mode: 多 provider 適配（anthropic / openai / qwen / ollama / custom）
- per-node override（e.g. dim6 audit 用 sonnet）
- workspace `LLM_BACKEND` block 讀取

### F-4 graph.py + nodes/ (~1150 LOC)

- StateGraph + 11 agent nodes 骨架
- Supervisor pattern @Lead → 條件式 route 至各 node
- Static edges 70% / Conditional edges 30%
- 7-8 HITL interrupts via `interrupt()` + Command resume

### F-5 mcp_server.py (~250 LOC)

MCP server 暴露 3 tools:

- `dispatch(request: str)` — 觸發 LangGraph 跑全 graph
- `dim6_audit()` — 跑 design audit subgraph
- `walkthrough(scenarios: list)` — 跑 integration walkthrough

### F-6 subgraphs/ (~300 LOC)

- `auditor_6dim.py` — 6 並行 dim audit + aggregate
- `hotfix_tier_upgrade.py` — paused → @Lead 接手 → 派新 heavy ticket
- `multi_signal.py` — ≥2 priority fan-out / ≥3 ambiguous interrupt
