## 三、設計細節

### L-1 ref-validator recursion patch

當前 `tests/ref-validator.mjs` `scanRefs()` 用 `readdirSync(dir).filter(x => x.endsWith('.md'))` 平面掃描。

改為遞迴掃描（含 `skills/users/` / `skills/templates/` / `skills/examples/` / `skills/checklists/`）：

```js
function walkMd(dir, results = []) {
  for (const entry of readdirSync(dir, { withFileTypes: true })) {
    const path = join(dir, entry.name);
    if (entry.isDirectory()) walkMd(path, results);
    else if (entry.name.endsWith(".md")) results.push(path);
  }
  return results;
}
// 取代原 readdirSync().filter(...)
```

對應 schema-validator / agents-overview-sync-validator 等掃 skills/ 的 validator 同步檢查。
