# PROPOSAL_502_024: Agent-Driven Onboarding

## 一、背景

User 反饋（2026-05-04）：

- `init-workspace.mjs` 在 Windows 環境無法執行（readline TTY / 路徑差異）
- 互動模式問太多問題；多數可由 agent 從 codebase 自動推導
- 應改成 agent 對話內驅動；只在「真的不確定且必須立即決定」才 multi-choice 詢問
- 其他細項可 defer 至實際遇到時再補

## 二、設計

### 三軌定位調整

| 軌道                                | 適用                                              | 工具                                 |
| ----------------------------------- | ------------------------------------------------- | ------------------------------------ |
| **A（agent-driven；推薦 default）** | 任何 LLM 環境（Claude Code / Qwen / Antigravity） | LLM Read/Write tools                 |
| B（互動 CLI；fallback）             | 純 terminal、無 LLM                               | `node init-workspace.mjs`            |
| C（YAML 預設；非互動）              | CI / 自動化部署                                   | `init-workspace.mjs --config <yaml>` |

### Agent-driven 原則

1. **Auto-detect 優先**：scan `package.json` / `pom.xml` / `requirements.txt` / `go.mod` / `Cargo.toml` / `*.csproj` / git remote / 子目錄結構推導 80% 欄位
2. **Defer 為 default**：大多 schema 欄位可填預設或留空；首次 dispatch 時遇缺才補
3. **Multi-choice 優於 free-form**：必須詢問時，提供 2-4 個選項讓 User 點選
4. **Required 才阻斷**：只有 schema `required: true` 才阻斷；optional 一律先建後補

### 自動偵測對照表

| 訊號來源                                      | 推導欄位                                  |
| --------------------------------------------- | ----------------------------------------- |
| 目錄名 / git remote URL                       | workspace name                            |
| `package.json` `dependencies`                 | tech-stacks 候選（match `MANIFEST.yaml`） |
| `package.json` `name` / `description`         | description seed                          |
| 子目錄結構（`auth/` `payment/` `inventory/`） | domains 候選                              |
| `tsconfig.json` / `pyproject.toml` 等         | runtime 推導                              |
| 既有 `.git/HEAD` branch                       | initial commit context                    |
| 既有 `docs/` / `tests/`                       | maturity 提示                             |
