## 一、問題描述

**根因分類**：`ARCH`（DoD 自評分散於多 rule，無統一驗收機制）

自我評比報告：
- 5.1 指令遵循度 = **3.5/5**（規則完整但無實測數據 + DoD 自評分散）

DoD 自評現狀分散於：
- `backend.md §s10 DoD 自評機制`
- `frontend.md §s08 DoD 自評機制`
- `qa.md §s12 DoD 自評機制`
- `reviewer.md §s09` 部分提及
- `security.md §s04 DoD 自評`
- `@Retro §產出物 DoD 自評規範`（RULES_DESIGN_GUIDE §七）

缺口：
- 沒有**統一的階段轉移 Gate Check** 自動驗收 DoD 是否達成
- @Lead Gate Check 輸出（`✅ Gate Check ✔ S<X>→S<Y>`）不含 DoD 合規證據

## 二、根因分析

- **現況**：各 Agent 自評 → 回報 @Lead → @Lead 人工判斷 Gate Check
- **缺口**：無「DoD 達成率」量化追蹤，長期無法觀察長程一致性趨勢

```
## 四、Gate Check Auto-Audit（由 @Lead 執行）

`@Lead` 收到 DoD 自評後執行自動驗收：

1. 讀取回報中的「通用核心」與「Agent 擴充」計數
2. 若任一項為 X/N（非 ✅）→ **拒絕進入下一階段**，退件補齊
3. 若全部 ✅ → 寫入 `docs/DoD_AUDIT_LOG.md` 新一行
4. 輸出 Gate Check 短指令（依 `lead.md §s_state_anchor` 第 7 條）

## 五、禁止行為

- **絕對禁止** 繞過 DoD 自評直接回報完成
- **絕對禁止** @Lead 未讀取自評結果即執行 Gate Check
```
