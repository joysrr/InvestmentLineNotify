## 三、提案內容

### 3.1 新建 `.agents/tests/agents-overview-sync-validator.mjs`

5 項自動掃描與比對：

```javascript
// 1. Agents 數對齐
//    docs/agents-overview.md §2.1 表格行數 vs ls .agents/rules/*.md
//    （排除 system-prompt.md；計 12 個 Agent）

// 2. Patrol 範圍對齐
//    docs/agents-overview.md §4.2 P-XX 表格範圍 vs assistant.md §s05 條目
//    （或 patrol-notification-catalog.md §A 計數）

// 3. Rules 版本對齐
//    docs/agents-overview.md §9.2 版本表 vs RULES_VERSION_INDEX.md

// 4. 系統參數對齐
//    docs/agents-overview.md §7.1 參數表 vs SYSTEM_THRESHOLDS.yaml top-level keys

// 5. 產出物對齐
//    docs/agents-overview.md §9.3 產出物清單 vs grep "produces:" .agents/rules/*.md
```

退出碼：
- 0 = 全部對齐
- 1 = 1-2 項不一致（warning）
- 2 = ≥ 3 項不一致或關鍵項目（如 Agents 數）不一致（error）

### 3.2 整合至 run-all.sh

於現有四腳本之後新增第五腳本呼叫；warning 不阻斷 commit（依 PROPOSAL_019 政策）

### 3.3 失敗時的修補指引

validator 輸出明確的 diff（哪份檔案 / 哪個區段不一致），協助 @Lead 快速修補。
