## 三、設計細節

### D-1 auditor.md 加 MemPalace baseline-search hook

`rules/auditor.md §s03` 第 3 條（baseline 比對）擴充 1-line：

```
3. **baseline 比對**：若 `AUDIT_HISTORY.md` 存前次紀錄，要求子 Agent 比對；
   **同時**派遣 prompt 內可注入 `mempalace.search "<維度關鍵詞>"` 查 strategy_context
   歷史評分趨勢（read-only；不違反 auditor-rubric-iron Rule #2/#3）。
```

達成 12/13 → **13/13 全 agent rules 整合**；補上 PROPOSAL_502_002 缺口。

token impact：auditor.md 估 +30 tokens；遠低於 worker tier 1500 上限。

### D-2 lead.md §s_memory_palace 加 dispatch 阻斷條款

skills/memory-operations.md:177 已寫「>5000 阻斷派發」但 lead.md 未強制。補 1-line：

```
- `mempalace status` drawer count > `COMPRESS_ERROR_THRESHOLD` (5000)
  → @Lead **暫停派發**（即使任務 ready），先呼叫 `mempalace compress`
  完成後恢復；同步通知 @Assistant 寫 P-XX 提示。
```

token impact：lead.md 1722 → ~1760（+38；orchestrator tier 1800 上限；剩 40 token headroom；可接受）。

### D-3 skill consolidation（schema vs operations）

`skills/memory-palace-schema.md` 縮減原則：

- 保留：Wings/Rooms/Drawers shape + INDEX schema + frontmatter contract
- 刪除：操作流程（§3.1/§3.2/§3.3 → 統一交 memory-operations.md §2）+ §6 Hybrid Fallback（→ memory-operations.md §2.5）
- 加指針：「操作流程見 `skills/memory-operations.md §2-§6`」

預估減 ~200 tokens；無功能變更。

### D-4 assistant.md §s04 加 PENDING_RED_EXPIRE 指針

§s04 異常判定表「🔴>PENDING_RED_EXPIRE→立即報」之後加 1-line：

```
（持續 🔴 額外觸發：§s07「持續 🔴 自動歸檔」寫 drawer；參見 PROPOSAL_502_003 C-4）
```

讀者跨 section 跳轉時不會漏看 archival 副作用。

### D-5 mempalace-auto-mine.sh header 註解修正

當前 header 寫「退出碼 1 = 不阻斷 commit」，但 `--staged` 旗標暗示 pre-commit 用法（exit 1 會擋）。修正：

```bash
# 退出碼：
#   0 = 成功 / 跳過（無變動或冪等）
#   1 = mempalace 命令失敗
#       - post-commit / Claude Code PostToolUse 安裝 → 不阻斷下游
#       - --staged + pre-commit 安裝 → 會阻斷 commit（建議改裝 post-commit）
```

無 code 變更；只修文字契約。

### D-6 PROPOSAL_502_002 §43 勘誤

當前：「@Auditor 已整合（auditor-rubric-iron immutable 引用）」
更正：「@Auditor 暫未整合 — 因 auditor-rubric-iron Rule #2/#3 限制；於 PROPOSAL_502_004 D-1 補 read-only baseline-search hook（不違反 iron-rule）。」

完成性宣稱誠實化；保留歷史脈絡。
