## 二、決策（依 PROPOSAL_20260430_002 v0.1 立案）

### D1=B：Memory Palace = framework + workspace 雙層

- `.agents/memory/`（framework；可跨專案搬運）
- `workspaces/<active>/memory/`（project-specific；不搬運）

### D2=C / D3=C：三層職責

| 層                  | 職責                                                | 搬運性     |
| ------------------- | --------------------------------------------------- | ---------- |
| `decisions/` (ADRs) | **WHY**（決策動機 + 替代方案 + 後果）               | framework  |
| `skills/`           | **HOW**（流程 / 範本 / 檢查表 / 範例）              | framework  |
| `memory/`           | **WHAT happened**（歷史脈絡 + 失敗教訓 + 對話記憶） | dual layer |

### D4=A：rule token 上限 ≤ 5K（warn=3000；block=4000；最終目標≤1000）
