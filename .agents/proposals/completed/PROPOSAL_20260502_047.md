| T   | gap | 動作                                                           |
| --- | --- | -------------------------------------------------------------- |
| T-5 | C-1 | 新建 `tests/condition-claim-validator.py`（19→20th validator） |

**設計**：

- 掃 ADR / skill / task markdown 中「condition-claim 模式」字樣：
  - `validator 驗 X` / `validator 加 X 檢查` / `validator 加 enum X`
  - `patrol P-N 偵測 X` / `新建 P-N`
  - `agent 必執行 X` / `sub-agent 必寫 X`
- 反查實作對齊：
  - validator claim → grep `tests/*.py` 含對應檢查
  - patrol claim → grep `patrol-notification-catalog.md` 含 P-N 條目
  - agent action claim → grep 對應 rule/skill 行為條文
- 不對齊 → fail with drift 報告（含 claim 位置 + 缺失實作位置）
