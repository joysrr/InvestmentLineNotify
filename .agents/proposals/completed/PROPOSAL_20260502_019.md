# PROPOSAL_20260502_019: Platform compatibility layer

## 一、目標

User 詢問框架支援哪些 harness（Claude Code CLI / Web / Antigravity / 自建 Qwen Agent）。實際分析後現況：

- **設計**為 multi-harness 友善（markdown rules / 純 Node validators / mempalace 獨立 CLI）
- **實作**深度耦合 Claude Code（sub-agent dispatch / `.mcp.json` / hooks pattern / 工具命名）
- **無對外文件** 說明各 harness 支援度 + 移植路徑

本提案補 platform compatibility 三件套：

| #   | 項目                               | 用途                                           |
| --- | ---------------------------------- | ---------------------------------------------- |
| T-1 | `docs/PLATFORM_COMPATIBILITY.md`   | 4 harness × N feature 對照表 + 限制 + 移植成本 |
| T-2 | `tasks/harness-adapter-pattern.md` | adapter 設計指南（4 個 adapter 點 + 範例）     |
| T-3 | `scripts/platform-detect.mjs`      | 自動偵測當前 harness + capability 旗標         |

不在本提案：

- 真實 Antigravity / Qwen-Agent adapter 實作（按需做；本提案只給設計指南）
- web mode 完整 fallback wiring（platform-detect 提供 detect + 降級提示；具體 wiring 視 User 真實使用場景再做）

## 二、執行紀錄

### T-1 PLATFORM_COMPATIBILITY.md（新建）

`.agents/docs/PLATFORM_COMPATIBILITY.md` 涵蓋：

- 4 harness（Claude Code CLI / Claude Code Web / Antigravity / Qwen-Agent）對照表
- 12 capability dimensions（markdown rules / 工具 / sub-agent / MCP / hooks / 持久 state / 等）
- 每 harness 已知限制 + workaround
- 移植成本估算（hr）+ 風險區
- 部署建議

### T-2 harness-adapter-pattern.md（新建）

`.agents/tasks/harness-adapter-pattern.md` 涵蓋：

- 4 個 adapter 切入點：(a) sub-agent dispatch (b) MCP integration (c) hooks (d) file system
- 每點介面抽象（pseudo-interface 規格）
- 範例：Qwen-Agent adapter 概念實作
- adapter 不應違反的 invariant（rules / iron-themes 不修）

### T-3 platform-detect.mjs（新建）

`.agents/scripts/platform-detect.mjs` 自動偵測：

- 檢查 `CLAUDE_CODE`（env var）/ `process.env.ANTHROPIC_API_KEY` / sandbox 標記
- 檢查 `which mempalace-mcp` / `node` / `python3` / mempalace status
- 檢查 `.mcp.json` / `.claude/settings.local.json` 存在性
- 輸出 JSON: `{ harness, capabilities, fallbacks, warnings }`
