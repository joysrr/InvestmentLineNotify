## 一、背景與來源

**來源文件**：`docs/plans/archived/draft_perplexity_suggestion.md`
- 由其他 Agent 審核系統後產出的分析報告
- 報告整體方向正確，但部分技術細節已過時（如提到 v2.5，現已為 v2.6）
- 核心缺口分析與分階段改善建議具參考價值

**系統現況摘要**（經本分析驗證）：
- ✅ 0050 DCA / 00675L 槓桿戰術部位已明確區分
- ✅ `computeGrossLeverage`、風控參數（marginCallThreshold / frozenZone / protectTrigger）已實作
- ✅ RSI / KD / MACD / MA20 / ATR、VIX override、MacroSentiment 已整合
- ✅ `analyzeMarginRisk` / `analyzeSurvival` / `analyzeCapitalDecoupling` 風控模組已存在
- ✅ `maxDailyLoanIncreasePct` / `maxRollingLoanIncreasePct` 槓桿節奏控制已實作

**主要缺口**：
1. 生命週期槓桿軌跡尚未完全程式化為第一級條件
2. VIX / MacroSentiment 仍以「懲罰分數」間接影響，未升級為硬條件
3. 缺乏整合性的 Portfolio Health 儀表板（紅黃綠燈號）
4. 策略變更治理流程尚未 formalize

## 四、預期效果

| 改善項目 | 現況 | 優化後 | 提升 |
|---------|------|------|:----:|
| 生命週期槓桿軌跡 | 分散在多處，未集中管理 | 集中於 `lifecycleEngine.mjs`，可配置化 | 可維護性 +80% |
| Portfolio Health | 需查閱多個技術指標 | 紅黃綠燈號，一眼可懂 | 使用者體驗 +60% |
| VIX / Regime 約束 | 間接影響 scoring | 硬條件，強制 Sell-only / 降槓桿 | 風險控制 +40% |
| 策略變更治理 | 無正式流程 | PROPOSAL + 回測 + 雙簽 | 合規性 +100% |
