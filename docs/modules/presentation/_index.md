# 入口與通知層 (Presentation Layer)

本目錄負責將策略引擎產出的決策結果，轉化為人類可讀的介面，以及處理外部的互動請求。

## 模組列表

- [`bot.md`](./bot.md)：記錄 Telegram Bot 的指令入口、權限控制與防呆鎖定機制。
- [`notifications.md`](./notifications.md)：記錄戰報格式化、分流派送機制，以及 Mini App 卡片串接。

## 核心設計理念

1. **展示與邏輯解耦**：Presentation 層絕對不能包含任何投資策略邏輯，只負責「接收資料」與「呈現」。
2. **多模態呈現**：系統支援純文字詳盡模式與 WebApp 精簡卡片模式，由環境變數動態切換。
