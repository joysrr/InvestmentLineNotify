# 新聞頁 UX 規格 (News Page UX)

本文記錄 CARD-5.4（新聞頁精修）驗證並補建的新聞頁 UX 規格。NewsCard 四層結構由 CARD-02 建立，CARD-5.4 僅驗證結構、補齊測試，並執行三處小修（hover 回饋、空狀態文案、loading 狀態統一）。

## NewsCard 四層結構

| 層級 | Class                                       | 用途                                     | 設計 token                     |
| ---- | ------------------------------------------- | ---------------------------------------- | ------------------------------ |
| L1   | `.news-title`                               | 標題，粗體                               | `--iln-text`                   |
| L2   | `.news-summary`                             | 摘要，最多 3 行，`-webkit-line-clamp: 3` | `--iln-hint`                   |
| L3   | `.news-source` / `.news-time`               | 來源與時間                               | `--iln-text-sm` / `--iln-hint` |
| L4   | `.news-badge.featured` / `.news-tag.picked` | 精選 / 已入選徽章                        | `--iln-warn-*` / `--iln-ok-*`  |

整卡可點擊（`cursor: pointer`），`hover` 顯示 `border-color: var(--iln-link)`，`active` 顯示 `opacity: 0.7`。

## 兩個 tab 的區分

| Tab      | 徽章標記                                          | 頁首說明                                         |
| -------- | ------------------------------------------------- | ------------------------------------------------ |
| 精選報告 | 每則有「精選」徽章 (`.news-badge.featured`)       | 「每日精選由系統依主題篩選，完整新聞請見新聞池」 |
| 新聞池   | 可匹配項有「已入選精選」標記 (`.news-tag.picked`) | 「所有抓取的新聞，依時間排序」                   |

不得合併兩個 tab（CARD-5.4 禁止條款）。

## 狀態呈現

兩個 tab 均統一使用共用組件，不得手寫狀態 UI：

| 狀態    | 組件                                              | 說明                                                                                     |
| ------- | ------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| loading | `LoadingSkeleton` (`variant="card"`, `:rows="3"`) | 兩個 tab 均適用                                                                          |
| empty   | `EmptyState`                                      | 精選報告：「今日尚無精選報告，請稍後再試」；新聞池：「新聞池目前為空，排程可能尚未執行」 |
| error   | `ErrorAlert` (`:show-retry="true"`)               | 兩個 tab 均適用，可重試                                                                  |

## 空狀態文案（計畫建議）

- 精選報告：「今日尚無精選報告，請稍後再試」
- 新聞池：「新聞池目前為空，排程可能尚未執行」

新聞池文案保留「排程可能尚未執行」診斷提示，告知使用者這不是新聞不存在，而是系統尚未跑排程。

## 備註

本文件於 CARD-5.4 補建，記錄 CARD-02 已實作的結構與 5.4 的狀態統一修正。若後續 5.6 收口時需要更新，請與此文件同步。
