# Kelly 與動態合理槓桿套用評估

## 結論

PTT 討論的模型可以作為 InvestmentLineNotify 的**研究型風險框架**，但不能直接把歷史平均報酬、固定波動率、`3.15x` 或半 Kelly 結果當成 00675L 的即時槓桿建議。

本階段只採用其風險拆解概念：

- 預期超額報酬
- 融資／產品成本
- 波動率
- 估值位階
- LETF 每日重設與路徑風險
- 維持率與個人負債壓力

輸出限於預警與禁止新增 00675L，不自動下單、不自動調整槓桿、不自動產生減碼指令。

## PTT 文章核對

### 可採用的核心觀念

1. Kelly 是在特定報酬分布假設下，最大化長期幾何成長的理論工具。
2. 半 Kelly 是對參數估計誤差、回撤與心理承受度的保守縮放。
3. 資金成本會影響槓桿是否值得使用。
4. 高估值通常意味著未來預期報酬降低；低估值可能提高預期報酬，但不是短期反轉保證。
5. 場外借款、期貨與 LETF 的成本與清算機制不同，不能只用同一個槓桿倍數比較。
6. 動態模型應使用當期資料，而不是永久固定一組歷史參數。

### 不可直接採用的部分

- `14.15%` 歷史年化報酬不能直接代表未來預期報酬。
- `20%` 波動率不能永久固定；應說明估計窗口、資料區間與制度變化。
- `1.55%` 成本不能直接套用所有台股槓桿工具，也不能忽略目前實際產品費用、期貨基差與交易摩擦。
- 標的指數的 Kelly 倍數不能直接套用到 00675L，因為 00675L 是每日重設 ETF。
- 半 Kelly 是風險縮放方法，不是「安全」或避免虧損的保證。

## 理論分層

### 1. 靜態 Kelly（研究基準）

簡化形式：

```text
L_kelly ≈ expected excess return / variance
```

此式只有在報酬、成本與波動率的定義一致，且估計值對未來仍有代表性時，才可作為研究基準。

### 2. LETF 產品層修正

00675L 必須額外納入：

- 每日重設造成的複利偏離
- 再平衡滑移
- 高波動時放大的追蹤誤差
- 管理費、期貨／融資成本與交易摩擦
- 連續下跌、跳空與震盪路徑

因此應先估計產品本身的風險／報酬，再決定配置比例，不能只把 00675L 視為「0050 的 2 倍」。

### 3. 估值動態化

若把 PE、EPS 或其他估值資訊納入，合理做法是調整「預期報酬區間」或風險分級，而不是宣稱能精準預測高低點。

### 4. 個人安全限制

即使模型給出較高槓桿，也必須再套用：

```text
L_recommended = min(
  0.5 × L_kelly,
  個人核定上限,
  維持率安全上限
)
```

其中半 Kelly 只是保守縮放，不是安全保證。

## 對目前系統的建議整合

### 本階段

- 使用現有雷達做高波動／重大衝擊預警。
- 重大警報時禁止新增 00675L。
- P0 固定 0050 定期定額不受影響。
- 警報卡片分開說明 0050 與 00675L。
- 資料不足時回傳不可判讀，不以零值代替。

### 後續研究

先建立只讀計算器，不接交易動作：

```text
L_current = 00675L 方向曝險 / 投資組合淨資產
L_kelly = f(預期超額報酬、產品成本、波動率、估值位階、路徑耗損)
```

計算器必須輸出公式版本、資料期間、來源、缺值狀態與假設，不只輸出單一倍數。

### 尚未具備前置條件前不得啟用

- 逐期 EPS／估值資料
- 可靠的 0050／加權指數歷史序列
- 00675L 實際價格與基準指數對照
- 產品成本與追蹤誤差估計
- 維持率、借款利率與資產負債資料契約
- 歷史回測與壓力測試
