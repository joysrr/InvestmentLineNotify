## 1. 專案背景與核心原則

### 1.1 升級背景
本系統現有架構具備完善的風控閘門（維持率狀態機、00675L 占比例再平衡、極端恐慌與隔夜衝擊雷達）。為了讓系統從「被動防備極端風險」升級為「具備數學底氣的動態決策模型」，本計畫導入四大量化金融理論：**凱莉公式 (Kelly Criterion)**、**拉普拉斯肥尾效應 (Laplace & Fat-Tail Risk)**、**生命週期投資理論 (Lifecycle Investing)** 以及 **托賓分離定理與波動損耗 (Tobin's Separation & Volatility Drag)**。

### 1.2 三大開發原則
1. **不破壞現有防護網：** 既有的維持率四層狀態機（135%/145%/160%/180%）與總曝險天花板（2.5x Ceiling / 3.0x HardCap）維持原樣，作為系統不可撤銷的硬性底線。
2. **理論計算層 (Theoretical Layer) 獨立化：** 新增獨立計算模組，輸出結果用於「前端 UI 視覺化（增強投資底氣）」與「影子觀測模式（Shadow Mode Log）」，暫不直接阻斷自動下單。
3. **消除無效技術債：** 徹底移除或封存現有無法運作的 `runMacroCompare.mjs` 歷史回測模組，改以輕量級「情境壓力測試引擎 (`stressTest.mjs`)」作為系統防禦網的驗證手段。

## 2. 實際資產與理論公式之動態綁定架構

系統每日抓取最新行情（`p_0050`, `p_00675L`）後，將使用者輸入的真實庫存數據寫入資料管道，動態計算基礎資產層與理論層指標。

```
[使用者真實庫存輸入]
  ├── 0050 持有股數 (qty_0050)
  ├── 00675L 持有股數 (qty_00675L)
  └── 總負債金額 (total_debt)
       │
       ▼ (結合 API 即時股價 p_0050, p_00675L)
┌────────────────────────────────────────────────────────┐
│ 基礎資產動態算式                                         │
│ 1. 0050 市值 V_0050 = qty_0050 × p_0050                 │
│ 2. 00675L 市值 V_00675L = qty_00675L × p_00675L         │
│ 3. 財務資本 FC (帳戶淨值) = V_0050 + V_00675L - total_debt │
│ 4. 總方向曝險 E_gross = V_0050 + (V_00675L × 2)          │
│ 5. 當前總槓桿 L_current = E_gross / FC                  │
│ 6. 質押維持率 Maintenance = (V_0050 + V_00675L) / total_debt│
└────────────────────────────────────────────────────────┘
       │
       ▼ (代入理論計算模組)
┌────────────────────────────────────────────────────────┐
│ 理論計算層 (Theoretical Layer)                          │
│ 1. 凱莉極限 (Kelly)    : 比對 L_current 與 L_max (2.38x) │
│ 2. 生命週期 (Lifecycle) : 真實人生曝險 E_gross / (FC + HC)│
│ 3. 拉普拉斯 (Laplace)   : 倒推大盤容忍跌幅 1 - (160% / M%) │
└────────────────────────────────────────────────────────┘
```

## 3. 四大理論核心公式與參數設定

### 3.1 凱莉公式（槓桿幾何成長天花板）
*   **參數設定：**
    *   預期年化報酬率 $\mu = 12\%$ ($0.12$)
    *   年化波動率 $\sigma = 20\%$ ($0.20$)
    *   借貸年利率 $r = 2.5\%$ ($0.025$)
*   **極限凱莉槓桿 ($L^*$)：**
    $$L^* = \frac{\mu - r}{\sigma^2} = \frac{0.12 - 0.025}{0.20^2} = 2.375\text{x}$$
*   **半凱莉安全區 ($L_{\text{half}}$)：**
    $$L_{\text{half}} = L^* \times 0.5 = 1.1875\text{x} \approx 1.19\text{x}$$

### 3.2 生命週期投資理論（33 歲人力資本動態模型）
*   **參數設定：**
    *   當前年齡：33 歲，預計退休年齡：65 歲，剩餘工作期 $N = 32$ 年。
    *   每年固定可投入 DCA 資金 $C_0 = 360,000$ 元（每月 3 萬元）。
    *   預設薪資成長率 $g = 0\%$（可調），預設折現率 $d = 0\%$（可調）。
*   **人力資本 ($HC$) 計算公式：**
    $$HC = \sum_{t=1}^{N} \frac{C_0 \cdot (1 + g)^{t-1}}{(1 + d)^t} = 360,000 \times 32 = 11,520,000\text{ 元}$$
*   **人生真實總曝險比例 (True Exposure Ratio)：**
    $$\text{True Exposure} = \frac{E_{\text{gross}}}{FC + HC}$$

### 3.3 拉普拉斯模型（維持率倒推崩盤容忍度）
利用當前質押維持率 ($M$)，倒推大盤暴跌多少 $\%$ 會觸發系統的保護機制 ($160\%$) 或斷頭危機 ($135\%$)：
*   **防禦觸發容忍跌幅：** $\text{Crash Tolerance}_{\text{Protect}} = 1 - \left(\frac{160\%}{M}\right)$
*   **斷頭危機容忍跌幅：** $\text{Crash Tolerance}_{\text{MarginCall}} = 1 - \left(\frac{135\%}{M}\right)$

### 3.4 托賓分離定理與逆價差紅利
在計算 00675L 的長期持有成本時，納入台股期貨常態逆價差補貼（年化約 $2\% \sim 4\%$），抵消波動拖累（$\frac{1}{2}L^2\sigma^2$）。預設將 00675L 視為具備高貼息效益之 2 倍曝險工具。

| 劇本名稱 | 市場情境描述 | 模擬大盤價格序列 | 系統驗證目標 |
| :--- | :--- | :--- | :--- |
| **劇本 A：2020 COVID 熔斷型** | 10天內極端暴跌 -25%，VIX > 45，隨後劇烈 V 轉 | `[-3.5%, -4.0%, -6.5%, -5.0%, +2.0%, -4.5%, +5.0%, +4.0%, -2.0%, +3.0%]` | 驗證維持率跌破 160% 時停扣 00675L；VIX 飆升時啟動 Triple-Gate 右側解鎖鎖定。 |
| **劇本 B：2022 陰跌熊市盤整** | 連續 3 個月緩跌 -30%，無大反彈 | `[-2.0%, -1.5%, -3.0%, +1.0%, -2.5%, -2.0%, -3.5%, +0.5%, -2.0%, -1.5%]` | 驗證 P0 0050 定額 DCA 未被警報誤殺；Regime 切換至 `BEAR_CHOPPY` 啟動阻尼。 |
| **劇本 C：2024/08 單日千點閃崩** | 單日大盤暴跌 -8.5%，SOX/TSM ADR 隔夜重挫 | `[-1.0%, -8.5%, +3.5%, -1.5%]` (搭配 z-score $\le -2.5$) | 驗證 `overnightShockRadar` 在開盤前凍結 00675L；觸發極端恐慌 0050 分批定錨。 |
| **劇本 D：高估值修復與高位修正** | PB 百分位達 P95 (極度高估)，隨後回檔 -12% | `[-1.5%, -2.0%, -3.5%, -2.0%, -3.0%]` (PB PR = 0.95) | 驗證影子模式 (Shadow Mode) 正確輸出降槓建議 Log，不影響現有系統運作。 |

## 6. 影子觀測模式 (Shadow Mode) 執行機制

1. **部署原則：** 當計算出動態修正槓桿（如因估值過高，理論建議將槓桿由 1.4x 降至 1.1x）時，僅進行靜態 Log 記錄與推播提醒。
2. **記錄格式範例：**
   ```json
   {
     "timestamp": "2026-10-23T08:30:00Z",
     "actual_decision": "ALLOW_DCA_0050_AND_00675L",
     "current_gross_leverage": 1.42,
     "shadow_mode_theory": {
       "recommended_leverage": 1.15,
       "kelly_max": 2.38,
       "reason": "Valuation PB PR at 0.95 (P95 upper bound), Laplace correction applied."
     }
   }
   ```
3. **觀察期：** 於真實市場中持續觀察 1~3 個月，比對實際系統決策與理論建議之績效與心理承受度差異，再決定是否升級為硬性阻斷規則。
