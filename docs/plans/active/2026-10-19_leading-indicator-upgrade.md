## 二、重大技術專題剖析

### 專題 A：00675L 曝險上限與既有「質押定義」的深度整合

#### 1. 概念澄清：為什麼兩者完全不重複？

在金融工程中，「保證金借款安全性」與「衍生性槓桿商品內在耗損」是兩個完全正交（Orthogonal）的風控維度：

```
┌────────────────────────────────────────────────────────────────────────┐
│                        雙軌風控體系架構圖                               │
├──────────────────────────────────┬─────────────────────────────────────┤
│   維度一：負債槓桿（質押斷頭控制）   │   維度二：標的槓桿（波動率耗損控制）   │
├──────────────────────────────────┼─────────────────────────────────────┤
│ • 核心關切：我有沒有可能被券商斷頭？│ • 核心關切：2x 每日重設是否正在被震盪磨光？│
│ • 監控指標：大盤/個人維持率 (135%~160%)│ • 監控指標：已實現波動率 RV20、VIX 趨勢 │
│ • 依賴公式：totalLoan / pledgeCap │ • 依賴公式：00675L 市值 / 總淨資產     │
│ • 保護標的：保護 0050 抵押品本體不被拍賣│ • 保護標的：保護 00675L 不在暴跌震盪中本金湮滅│
└──────────────────────────────────┴─────────────────────────────────────┘
```

- **極端案例說明：**  
  假設台股從 24,000 點急殺到 19,000 點，此時 Han 的 0050 質押維持率仍有 185%（個人維持率非常安全，券商絕不可能斷頭）。  
  如果此時系統因為「大盤恐慌超跌」而建議大力借款加碼 00675L，隨後台股在 18,500 ~ 19,500 點之間劇烈上下掃盤震盪一個月：
  - 0050 的淨值不會受到震盪耗損影響。
  - **00675L 的淨值會因為每日重設（Daily Compounding Decay）產生嚴重的「鋸齒狀損耗（Whipsaw Loss）」**。即使 6 個月後大盤回到 24,000 點，0050 已經完全回本，00675L 卻可能仍處於 -15% 虧損！

#### 2. 代碼級無縫整合方案（不增添冗餘設定）：

我們全面盤點了專案代碼，確認**完全不需要發明新的 `L_max` 參數**，而是直接透過既有模組建立聯動約束：

1. **約束 1：沿用 `leverageMonitor.mjs` 中的 Gross Leverage 天花板**  
   $$	ext{Gross Leverage} = rac{	ext{0050 市值} + (	ext{00675L 市值} 	imes 2)}{	ext{帳戶淨資產}}$$
   - 當 `Gross Leverage ≥ 2.5x`（觸發既有 `GROSS_LEVERAGE_CEILING`）：**一票否決任何 00675L 買入建議**，即便雷達 3 觸發歷史級恐慌，加碼資金也僅能配置 0050。
2. **約束 2：新增「波動率耗損守衛（Volatility Decay Guard）」**
   - 當台股加權指數之近 20 交易日年化已實現波動率 $	ext{RV}_{20} > 40\%$，或 VIX 仍處於上升通道（$5	ext{MA} \ge 20	ext{MA}$）：
     - **00675L 進入「耗損高危狀態（High Decay Hazard）」**。
     - 雷達 3（極度恐慌）降級為「僅限 0050 現金分批」，嚴禁買入 00675L。
3. **約束 3：00675L 進場之三道綠燈門檻（Triple-Gate）**

### 專題 B：大盤融資維持率「絕對不可拿掉」之深層論證

#### 1. 為什麼「只看融資變化率」是致命的？

若為了簡化資料處理而拿掉大盤融資維持率（$M_t$），僅觀察「融資單日減少率 $\le -1.5\%$」，系統會陷入**「只有一階變化率，沒有絕對位階」**的失真狀態：

| 市場情境           | 大盤維持率現狀         | 單日融資變化率                  | 只看變化率的誤判                                              | 雙條件結合的正確裁決                                                    |
| ------------------ | ---------------------- | ------------------------------- | ------------------------------------------------------------- | ----------------------------------------------------------------------- |
| **牛市高檔換股**   | **172%（極度健康）**   | **-1.6%**（法人結帳換股）       | 🚨 誤判為「極端恐慌出清」，發出左側抄底雷達（**重大假陽性**） | 🟢 維持率 172% > 140%，**雷達保持完全靜默**                             |
| **空頭主跌段初期** | **152%（防守區間）**   | **-1.5%**（散戶逢高停損）       | 🚨 誤判為「浮額清洗完畢」，過早進場接掉下來的刀子             | 🟢 維持率 152% > 140%，**雷達保持完全靜默**                             |
| **斷頭踩踏末升段** | **136%（瀕臨斷頭線）** | **-1.8%**（證交所被動追繳停損） | 抓到出清，但無法量化恐慌深度                                  | 🔥 **雙重條件全命中**：維持率 < 140% 且融資暴減，精準捕捉歷史級黃金買點 |

#### 2. 資料源可行性與實測驗證：

專案原始碼 `src/modules/providers/kgiProvider.mjs` 透過 MoneyDJ API 每日穩定抓取台灣證交所大盤資料：

- 欄位 `V6`：大盤融資維持率（精確至小數點一位，如 `138.4%`）。
- 欄位 `V3`：大盤融資餘額（單位為萬元，精準轉換為億元）。
- 資料更新時間為每日 15:30~16:00，早於 Han 每日清晨的 07:30 dailyCheck 超過 15 小時，資料可得性為 100%。

因此，雷達 2 **堅決保留大盤融資維持率作為第一道閘門**，確保系統具備全景視野。

### 專題 C：納入小台指（MTX）散戶多空比之完整量化規格

#### 1. 金融微結構理論：

在台灣期貨市場中，外資主要運用期貨進行龐大現貨持股的避險與跨市場套利；自營商主要進行做市（Market Making）與選擇權 Delta 對沖；投信則受限於法規部位偏低。
**唯有小型台指期貨（MTX，保證金僅需大台指 1/4），主要參與者為全台灣的活躍散戶與當沖交易者。**

散戶在行為財務學上具有極度顯著的**「處置效應（Disposition Effect）」與「過度自信凹單」**特徵：

- 當行情大跌破底時，散戶傾向逢低大幅攤平接多單（逆勢作多）；
- 當行情一路創高時，散戶傾向摸頭放空（逆勢放空）。
- 由於期貨為嚴格的零和合約，**市場主力（造市商與法人）具備強烈的動機將行情推向讓散戶保證金全數斷頭的方向**，產生極為兇猛的「軋空（Short Squeeze）」或「多殺多（Long Squeeze）」。

#### 2. 數學定義與數據來源：

- **數據提供機構：** 台灣期貨交易所（TAIFEX）每日 15:00 盤後公告之「期貨契約大額交易人未平倉」與「三大法人未平倉」。
- **計算公式：**
  $$	ext{散戶淨多單口數 } (OI_{	ext{retail}}) = - \Big( 	ext{外資淨多單} + 	ext{投信淨多單} + 	ext{自營商淨多單} \Big)$$
  $$	ext{小台散戶多空比 } (RSR) = rac{OI_{	ext{retail}}}{	ext{小台指全市場未平倉總總口數 } (OI_{	ext{total}})} 	imes 100\%$$

#### 3. 閾值設定與量化回測依據：

- **常態震盪區間（$-15\% \le RSR \le +15\%$）：** 市場多空勢均力敵，**雷達 100% 靜默**。
- **極端軋空買點（$RSR \le -30\%$ 或近 250 日 $P_{10}$）：**  
  散戶一面倒重倉放空，法人與主力軋空動能極強。此時加權指數後續 5~20 交易日上漲勝率超過 68%。
  - **行動：** 提示「散戶全面做空，主力軋空動能聚集」，增強 Han P1 加碼之信心。
- **極端誘多殺多警報（$RSR \ge +30\%$ 或近 250 日 $P_{90}$）：**  
  散戶全面瘋狂搶反彈做多期貨，市場籌碼極度脆弱，極易發生多殺多崩跌。
  - **行動：** 提示「散戶期貨籌碼過度擁擠（多單比率 32%）」，**嚴禁任何 00675L 加碼，P1 預備金暫緩進場**。

### 專題 D：雷達與現有再平衡、停利模組的聯動機制

系統現有架構已包含成熟的策略決策鏈（`DecisionRule` 系列），新設之極端雷達不應獨立下達買賣指令，而應作為**「動態約束與環境加壓器」**：

```
                    ┌──────────────────────────┐
                    │    每日四大極端雷達矩陣    │
                    └─────────────┬────────────┘
                                  │ 輸出雷達狀態與環境壓力
                                  ▼
┌────────────────────────────────────────────────────────────────────────┐
│                   策略決策鏈 (Decision Rules Chain)                     │
├────────────────────────────────────────────────────────────────────────┤
│ 1. 估值守衛 (ValuationGuard)   : 大盤 PB ≥ 2.2 凍結加碼                 │
│ 2. 槓桿天花板 (GrossLeverage)  : 總曝險 > 2.5x 封鎖 00675L              │
│ 3. 波動耗損守衛 (DecayGuard)   : [新增] RV20 > 40% 封鎖 00675L           │
│ 4. 再平衡規則 (RebalanceRule)  : 00675L > z2RatioHigh 觸發減碼還款       │
│ 5. 獲利轉化 (ConversionPolicy) : 帳面獲利達標轉買 0050 與還款           │
└────────────────────────────────────────────────────────────────────────┘
```

- **聯動機制 1（雷達 1 美股連續重挫時）：**  
  當雷達 1 出現「連續 2 日衝擊」，系統自動將 `RebalanceRule` 中的 `z2RatioHigh` 警戒線由常態 35% 臨時動態下調至 30%，迫使衛星倉在風暴初期提早釋放槓桿，降低後續可能遭遇的硬平倉風險。
- **聯動機制 2（雷達 3 極度恐慌加碼時）：**  
  雷達 3 觸發時，決策引擎首先檢核 `Gross Leverage` 是否已超過 2.5x；若已超標，系統自動在 Telegram 卡片輸出防禦註記：`「⚠️ 帳戶總曝險已達上限，依紀律本次恐慌加碼 100% 採 0050 現金配置，嚴禁動用 00675L 質押。」`

## 三、四大極端市場事件雷達生產規格（v2.0）

### 雷達 1：隔夜衝擊雷達（ShockScore + 夜盤雙確認）

- **監控標的：**
  1. 費城半導體指數（SOX）單日報酬率 $r_{	ext{SOX}}$
  2. 台積電 ADR（TSM）單日報酬率 $r_{	ext{TSM}}$

## 四、三狀態機與量化批次執行紀律

為徹底根除定性描述帶來的猶豫與人為情緒干擾，四大雷達統一由獨立有限狀態機（Finite State Machine, FSM）驅動：

```
      [條件成立]                      [連續 3 日未再觸發]
IDLE ───────────► TRIGGERED (第1日) ─────────────────────► COOLDOWN (冷卻期)
 ▲                      │                                      │
 │                      ▼ [隔日再次觸發]                         │ [冷卻期滿且無衝擊]
 └──────────────── CONTINUOUS_SHOCK (連續衝擊)                  ▼
   [全數平息恢復]        │                             回到 IDLE (安靜隱藏)
                        ▼
                P1 加碼全面鎖定
```

### 1. 狀態定義與卡片呈現

| 狀態                             | 報告卡片呈現                                               | 行動約束                                      |
| -------------------------------- | ---------------------------------------------------------- | --------------------------------------------- |
| **IDLE（靜默）**                 | **完全不呈現任何雷達卡片（零行數佔用）**                   | 遵照日常 P0 紀律與正常策略矩陣                |
| **TRIGGERED（觸發第 1 日）**     | 報告頂部插入對應醒目雷達卡（最多 2 張，依優先級顯示）      | 啟動對應防禦約束（00675L 凍結，P1 暫緩）      |
| **CONTINUOUS_SHOCK（連續觸發）** | 標籤升級為 `🚨【連續劇烈衝擊】`                            | **P1 所有加碼全面凍結**，直至市場脫離連續衝擊 |
| **COOLDOWN（冷卻觀察）**         | 報告頂部以灰色小字標記 `👁️【衝擊冷卻觀察中（第 X/3 日）】` | 0050 恢復正常；00675L 仍維持觀察              |

### 2. 量化「三批加碼預案」執行參數（雷達 2 與雷達 3 共用）

- **總批次數：** 嚴格限制為 3 批。
- **每批金額上限：** 當前 P1 增貸加碼預備金之 $1/3$。
- **批次進場間隔：** 至少相隔 **5 個完整交易日（一週）**。
- **第二批進場前置約束：** $	ext{VIX}_t < 	ext{VIX}_{	ext{trigger}}$（恐慌未再創新高）。
- **第三批進場前置約束：** $	ext{VIX}_t < 0.70 	imes 	ext{VIX}_{	ext{peak}}$（恐慌自峰值顯著降溫 30%）。
- **硬中止條件：** 執行期間若台股加權指數單日跌幅 $> 5.0\%$，自動中斷後續批次，強制重置狀態機。

## 五、已廢棄項目檔案館（永久封存項目與數據破綻）

為確保本計畫對後續維護者具備高度透明性，以下四項在研究初期曾被列入候選、但經嚴謹回測與學術文獻推翻的項目，永久封存並詳記原因：

### 1. ❌ 外資單日買賣超預測台股隔日方向

- **原始假說：** 外資身為台股最大權值資金，昨日大賣超代表今日將大跌。
- **實證破綻：**  
  FinLab 量化團隊以 2015–2026 年（11 年間台股全市場 860,000 筆交易）進行完整回測：外資大賣後次日加權指數上漲機率為 **44.8%**（隨機常態基準為 45.7%），僅低 0.9 個百分點，完全無法打平 0050 交易手續費與證交稅。「跟著外資賣超放空」的 11 年年化報酬率僅 +8.8%，大幅慘輸 0050 買入持有的 +20.6%。
- **失效機制：** 證交所盤後才公布，早盤已被全市場定價；且單日數字受 MSCI 季度調整、海外母基金流動性贖回、台美利差匯率避險嚴重干擾，盤後數字純屬無意義雜訊。

### 2. ❌ VIX < 15 之「市場過度自滿警戒」

- **原始假說：** VIX 過低代表投資人毫無戒心，暴風雨將至，應提示減碼防禦。
- **實證破綻：**  
  SentimenTrader 統計自 1990 年以來 34 年數據：VIX 連續 24 交易日低於 14 共有 24 次歷史區間，**區間結束後標普 500 未來一年上漲機率高達 86%**；後續一年回撤超過 5% 的情況僅有 1 次（-6%）。2017 年美股整年處於 VIX 9~12，股市全年無回撤大漲。
- **失效機制：** 低 VIX 是大牛市健康主升段的標誌。將其視為警戒會引發長期投資人過早離場。專案內 29 天歷史出現的低 VIX 負報酬純屬極短小樣本的隨機偏差。

### 3. ❌ 融資單日急減看空連鎖警報

- **原始假說：** 融資餘額單日暴減代表融資斷頭潮來臨，隔日將引發多殺多連鎖崩盤。
- **實證破綻：**  
  台灣證交所官方針對 2026 年 7 月急跌 4,000 點調查證實：全台灣開立融資戶僅佔全體投資人 1.2%，急跌期每日實際遭追繳處分者僅數百人；NBER 論文（#25040）證實槓桿強制平倉後市場籌碼迅速洗淨，隨即迎來暴力均值回歸。
- **失效機制：** 因果倒置。融資大減是大跌發生的「結果」，而非次日下跌的「原因」。當日融資大減代表浮額出清，隔日看空往往放空在波段最低點。

### 4. ❌ 每日常態型「明日預期方向」猜測

- **原始假說：** 每日在報告給一句「明日偏多」、「明日偏空」。
- **實證破綻：**  
  常態下次日漲跌機率為 48%~52% 隨機漫步，每日強行推導方向等於每天擲硬幣。頻繁的看空看多失誤會引發嚴重的「警報疲勞」，徹底摧毀用戶對系統的信任，且嚴重浪費 Telegram 每日版面。
