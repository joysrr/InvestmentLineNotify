## 核心初心與設計哲學（The Core Mission）

1. **告別後視鏡開車：** 徹底打破現行系統「大盤崩跌後才標記空頭、暴漲後才標記多頭」的滯後缺陷，提供**領先市場的盤前與盤後極端預警**。
2. **極端發聲，常態靜默（Silent by Default）：** 平時 90% 的常態交易日保持完全隱藏，不製造任何警報疲勞與資訊雜訊。
3. **P0 定期定額神聖不可侵犯：** 每月 3 萬元與增貸每 10 天 6 萬元為資產累積基石，雷打不動，不受任何短線雷達與市場恐慌約束。
4. **雙軌差異化行動紀律：**
   - **0050（核心定錨）：** 在大盤融資斷頭與歷史恐慌時，敢於在左側分批低接。
   - **00675L（衛星動能）：** 嚴格為「右側確認型工具」；暴跌當下堅決不當接盤俠，必須等待市場止跌反轉訊號明確才解放。
5. **架構職責分離（Sensors vs Guards）：**
   - **雷達群（Sensors）：** 專注於極端環境感測，輸出標準化的「市場狀態」與「紀律約束標籤」。
   - **風控護欄（Global Guards）：** 個人維持率、總槓桿上限由系統底層既有模組守護，雷達不越俎代庖進行複雜會計試算。

### 雷達 1：隔夜衝擊雷達（美股暴跌傳導 + 夜盤強度分級）

_解決痛點：美股半導體崩盤，隔日台股開盤暴跌，盤前缺乏預警。_

- **監控標的：** 費城半導體指數（SOX）、台積電 ADR（TSM）、台指期夜盤。
- **衝擊指數（ShockScore）：**
  $$	ext{ShockScore} = 0.5 	imes z(r_{	ext{SOX}}) + 0.5 	imes z(r_{	ext{TSM}})$$
- **觸發條件（AND）：**
  1. $|	ext{ShockScore}| \ge 2.0$ 且 $|r_{	ext{SOX}}| \ge P_{95}(|r_{	ext{SOX}}|, 250	ext{d})$
- **夜盤強度分級器（觸發後判斷市場共振程度）：**
  - **【強共振】（$|r_{	ext{night}}| \ge 1.0\%$ 且同向）：** 00675L 當日禁止買入；P1 當日暫緩。
  - **【普通確認】（$0.5\% \le |r_{	ext{night}}| < 1.0\%$ 且同向）：** 00675L 當日禁止買入；P1 當日暫緩。
  - **【背離鈍化】（$|r_{	ext{night}}| < 0.5\%$ 或逆向）：** 00675L 當日禁止買入；**P1 維持正常加碼**，卡片標記【夜盤抗跌背離】。
- **核心紀律：** P0 DCA 正常扣款；00675L 當日禁止買入（亦嚴禁在崩盤日強制砍倉低割）。

### 雷達 2：籌碼沉澱偵測器（大盤融資斷頭與出清速度）

_解決痛點：融資多殺多接近尾聲時，不敢進場撿便宜。_

- **監控標的：** 大盤融資維持率（$M_t$）、融資餘額單日增減率（$d_{	ext{margin}}$）。
- **觸發條件（雙條件嚴格過濾）：**
  1. **水位閘門：** $M_t < 140\%$ 或 $M_t < P_{10}(M, 250	ext{d})$
  2. **出清速度：** $d_{	ext{margin}} \le -1.5\%$（單日融資急減約 40~50 億以上）
- **核心紀律：**
  - **0050：** 散戶浮額出清，價值底浮現，啟動 0050 分批低接。
  - **00675L：** 維持凍結，必須等待市場價格右側確認。

### 雷達 3：歷史級極度恐慌雷達（雙重認證 + 右側價格敏銳三綠燈）

_解決痛點：面對 2020 熔斷或 805 股災等系統性恐慌，缺乏左側定錨與右側解鎖標準。_

- **觸發條件（雙重認證 AND）：**
  1. $	ext{VIX}_t \ge \maxig(28.0, \, P_{95}(	ext{VIX}, 750	ext{d})ig)$
  2. $	ext{CNN Fear & Greed Index} \le 20$
- **核心紀律：**
  - **0050（左側定錨）：** 啟動三批加碼預案，分批布局便宜籌碼。
  - **00675L（右側價格敏銳三綠燈）：** 觸發當下 100% 凍結；**僅在下列三道綠燈全亮時解放買入**：

### 雷達 4：小台指非三大法人多空對決雷達（極端籌碼逆向警報）

_解決痛點：散戶在期貨逆勢死扛多單，引發連鎖停損踩踏。_

- **監控標的：** 期交所小台指（MXF）未平倉量，計算散戶淨部位比率：
  $$RSR = rac{	ext{非三大法人淨部位}}{	ext{小台全市場未平倉總量 (OI)}} = rac{-( 	ext{三大法人淨部位合計} )}{	ext{小台全市場未平倉總量 (OI)}}$$
- **觸發條件與警報：**
  - **多殺多崩跌高危警報（散戶極度擁擠死扛）：**  
    $RSR \ge +30\%$ 或 $(RSR \ge P_{90}(250	ext{d}) 	ext{ 且 } RSR \ge +20\%)$。  
    **約束：凍結所有 P1 條件型加碼與 00675L 買入（防範連鎖多殺多踩踏）**。
  - **軋空多頭強訊號（散戶全面看空放空）：**  
    $RSR \le -30\%$ 或 $(RSR \le P_{10}(250	ext{d}) 	ext{ 且 } RSR \le -20\%)$。提示軋空動能聚集。
  - **常態震盪：** $-15\% \le RSR \le +15\%$ 保持 100% 靜默。

## 二、三狀態機流轉架構（State Machine）

系統採用清爽的單一計時狀態流轉，杜絕雙重計時與死條件：

```
                    [任一雷達滿足條件]
           ┌────────────────────────────────┐
           │                                ▼
        ┌────┐  [觸發次日無條件]   ┌──────────┐  [連續 5 日無雷達觸發]   ┌────┐
        │IDLE│ ─────────────────► │ TRIGGERED│ ────────────────────────► │IDLE│
        └────┘                    └────┬─────┘                           └────┘
          ▲                            │                                   ▲
          │                            ▼ [隔日再次觸發]                      │
          │                     ┌───────────────┐                          │
          │ ┌────────────────── │CONTINUOUS_SHOCK│ ◄───┐                    │
          │ │ [D+1無觸發平息]    └───────────────┘     │ [冷卻期再次觸發]     │
          │ │                          │               │                    │
          │ ▼                          └───────────────┼────────────────────┘
       ┌──────────┐                                    │
       │ COOLDOWN │ ───────────────────────────────────┘
       └──────────┘
```

1. **IDLE（常態）：** 90% 的日子維持在此狀態，Telegram 完全靜默。
2. **TRIGGERED（觸發首日）：** 發出極端預警卡片，套用行動約束。
3. **COOLDOWN（冷卻觀察期）：** 觸發次日進入。**只要連續 5 個交易日無任何雷達觸發，自動退回 IDLE**。
4. **CONTINUOUS_SHOCK（連續衝擊）：** 連續數日雷達觸發。隔一交易日（D+1）結算無觸發即視為「衝擊平息」，轉入 COOLDOWN 並重新計 5 日。
5. **多雷達合併：** 同一時間僅運行一個三批加碼計畫；5 日內多雷達相繼觸發時自動合併，進度不重置。

## 三、全域安全護欄（Global Guards）

雷達作為「感測器」，不負責繁瑣財務精算。系統層級以三道清晰護欄為底線：

1. **護欄一（P0 信仰護欄）：**  
   每月 3 萬常態 DCA ＋ 增貸每 10 天 6 萬，享有神聖豁免權，任何雷達皆不可暫停 P0。
2. **護欄二（P-1 個人維持率斷路器）：**  
   若個人維持率 $< 160\%$，一票否決全系統任何 P1 預備金加碼與 00675L 開倉，優先保護流動性，防範被迫平倉。
3. **護欄三（槓桿天花板與逆週期豁免）：**
   - 00675L 加碼後預期 Gross Leverage 嚴格 $\le 2.3	ext{x}$（保留安全緩衝）。
   - 0050 加碼後預期 Gross Leverage 嚴格 $\le 2.5	ext{x}$。在雷達 3 極度恐慌期間，享有逆週期豁免，暫時放寬至 $2.7	ext{x}$，避免在市場底部因淨值縮水產生「順週期停買」悖論。

## 六、上線驗收測試清單（TDD Test Cases）

- [ ] **TC-01（雙軌風控分流）：** 驗證四大雷達觸發時，0050 與 00675L 的行動指示明確分流（0050 左側低接、00675L 嚴格右側）。
- [ ] **TC-02（00675L 敏銳三綠燈驗證）：** 驗證恐慌觸發後，00675L 必須在 `VIX <= 0.8*peak`、`加權收盤 >= SMA5`、`RV20 < 35%` 三者同時成立時才解鎖。
- [ ] **TC-03（P-1 個人維持率斷路器）：** 驗證個人維持率 $< 160\%$ 時，一票否決所有加碼指示。
- [ ] **TC-04（雙條件籌碼出清）：** 驗證大盤維持率 $< 140\%$ 且融資單日減 $\le -1.5\%$ 同時滿足才觸發雷達 2。
- [ ] **TC-05（小台指 RSR 雙邊界）：** 驗證 TAIFEX 數據解析，驗證 $RSR \ge +30\%$ 或高分位且 $\ge 20\%$ 之過濾防護。
- [ ] **TC-06（狀態機平息與常態靜默）：** 驗證連續 5 日無事件自動回歸 IDLE，無警報輸出。
- [ ] **TC-07（P0 信仰特權豁免）：** 驗證任何雷達在任何狀態下，P0（每月 3 萬 + 增貸每 10 天 6 萬）均正常放行。
