### 1.1 Kelly Criterion（凱莉公式）

| 參數                    | 硬編碼值             | 合理性分析    | 建議            |
| ----------------------- | -------------------- | ------------- | --------------- |
| `borrowRate`            | **0.025** (2.5%)     | ⚠️ **不合理** | 🔴 **應動態化** |
| `productCostAdjustment` | **0.01** (1%)        | ✅ 合理       | 🟢 可保留       |
| `protectiveScale`       | **0.5** (Half-Kelly) | ✅ 合理       | 🟢 可保留       |

**詳細分析**：

#### `borrowRate: 0.025` 🔴 不合理

**問題**：

- 融資利率會隨市場變動（台灣融資利率 2024-2026 年在 2.3% - 3.5% 間波動）
- 硬編碼 2.5% 無法反映實際借款成本變化
- Kelly 公式對借款成本極度敏感（0.5% 差異可能改變最佳槓桿 10%+）

**影響**：

- **高估最佳槓桿**：實際利率 3.5% 時，系統仍按 2.5% 計算，會建議過高槓桿
- **低估風險**：利率上升時風險增加，但系統無感知

**建議改進**：

```javascript
// ❌ 當前（硬編碼）
borrowRate: 0.025;

// ✅ 改進方案
borrowRate: portfolio.effectiveBorrowRate ?? 0.025; // 從實際融資利率計算
```

**優先級**：🔴 **高優先** - 影響決策核心

---

#### `productCostAdjustment: 0.01` ✅ 合理

**合理性**：

- ETF 管理費 0050: 0.32%/年，00675L: 0.40%/年
- 交易成本（手續費 + 證交稅）：~0.3% 單趟
- 滑價成本：~0.2%
- **總計**：~1%/年 屬於合理估計

**建議**：🟢 保留硬編碼，可加註解說明組成

---

#### `protectiveScale: 0.5` ✅ 合理

**合理性**：

- Half-Kelly 是學術界與實務界廣泛接受的保守策略
- 降低 Kelly 公式對參數估計誤差的敏感度
- 符合用戶（Han）20-30 年長期投資的風險偏好

**建議**：🟢 保留硬編碼

### 1.2 Human Capital（人力資本）

| 參數           | 硬編碼值           | 合理性分析    | 建議            |
| -------------- | ------------------ | ------------- | --------------- |
| `cashFlows`    | **[1200000 × 25]** | ⚠️ **不合理** | 🟠 **應可配置** |
| `growthRate`   | **0** (0%)         | ⚠️ 保守但不準 | 🟡 可改進       |
| `discountRate` | **0.03** (3%)      | ⚠️ **不合理** | 🟠 **應動態化** |

**詳細分析**：

#### `cashFlows: Array.from({ length: 25 }, () => 1200000)` 🔴 不合理

**問題**：

- **完全硬編碼用戶（Han）的個人數據**
- 其他用戶無法使用此系統（單用戶系統可接受，但架構不優雅）
- 年收入 120萬、工作 25 年是 Han 的特定情況

**影響**：

- 若用戶收入改變（如轉職、加薪），系統無法更新
- True Exposure 計算會永久使用過時的人力資本估值

**建議改進**：

```javascript
// ❌ 當前（硬編碼）
cashFlows: Array.from({ length: 25 }, () => 1200000);

// ✅ 改進方案 A: 從用戶配置讀取
const humanCapitalConfig = strategyConfig.humanCapital ?? {
  annualIncome: 1200000,
  yearsRemaining: 25,
  growthRate: 0,
};
cashFlows: Array.from(
  { length: humanCapitalConfig.yearsRemaining },
  () => humanCapitalConfig.annualIncome,
);

// ✅ 改進方案 B: Mini App 輸入
// 在 Mini App 新增「人力資本設定」頁面，讓用戶輸入
```

**優先級**：🟠 **中優先** - 不影響決策但影響可維護性

---

#### `growthRate: 0` 🟡 保守但不準

**合理性**：

- **保守假設**：不假設未來加薪（符合審慎原則）
- **不準確**：台灣平均薪資成長率 ~1-2%/年（扣除通膨後實質成長 ~0-1%）

**建議**：

- 🟡 可改為 0.01（1% 實質成長）
- 或從配置文件讀取，預設 0%

**優先級**：🟡 低優先

---

#### `discountRate: 0.03` 🔴 不合理

**問題**：

- **無風險利率會變動**：台灣 10 年期公債殖利率 2024-2026 年在 0.8% - 1.5% 間
- 硬編碼 3% 遠高於實際無風險利率
- 導致人力資本被**嚴重低估**（折現率越高，現值越低）

**影響範例**：

```javascript
// 假設 25 年每年 120萬現金流
// discountRate = 1.5% (實際)
現值 = 25,800,000 TWD

// discountRate = 3.0% (硬編碼)
現值 = 20,900,000 TWD

// 誤差: 低估 19%
```

**建議改進**：

```javascript
// ❌ 當前（硬編碼）
discountRate: 0.03;

// ✅ 改進方案：從市場數據動態抓取
import { getTaiwanBondYield } from "../providers/bondProvider.mjs";
const discountRate = (await getTaiwanBondYield("10Y")) ?? 0.015;
```

**優先級**：🟠 **中優先** - 影響 True Exposure 計算

### 1.4 Laplace Criterion（拉普拉斯準則）

| 參數        | 硬編碼值     | 合理性分析    | 建議              |
| ----------- | ------------ | ------------- | ----------------- |
| `scenarios` | **4 個情境** | ⚠️ **不合理** | 🟠 **應歷史計算** |

**硬編碼情境**：

```javascript
[
  { name: "COVID 熔斷", maxLoss: 0.4 }, // -40%
  { name: "熊市震盪", maxLoss: 0.25 }, // -25%
  { name: "閃崩", maxLoss: 0.35 }, // -35%
  { name: "估值回歸", maxLoss: 0.2 }, // -20%
];
```

**問題**：

- **主觀臆測**：損失幅度並非基於歷史數據
- **靜態不變**：市場結構改變時（如 2008、2020）無法自動更新
- **缺乏學術依據**：Laplace Criterion 應該基於歷史情境分布

**建議改進**：

```javascript
// ❌ 當前（硬編碼）
scenarios: [
  { name: "COVID 熔斷", maxLoss: 0.4 },
  ...
]

// ✅ 改進方案：從歷史數據動態計算
async function calculateHistoricalScenarios(priceHistory) {
  // 分析過去 10 年的最大回撤
  const rollingDrawdowns = calculateRollingMaxDrawdown(priceHistory, [
    { window: 30, name: "閃崩" },      // 1 個月
    { window: 90, name: "熊市震盪" },   // 3 個月
    { window: 252, name: "長期熊市" },  // 1 年
  ]);

  return rollingDrawdowns.map(d => ({
    name: d.name,
    maxLoss: d.percentile95,  // 95% 信賴區間
  }));
}
```

**優先級**：🟠 **中優先** - 影響風險評估準確性

## 2. 市場數據參數（3 個）✅

### 位置：`src/scheduler/dailyCheckTheoreticalAdapter.mjs`, `src/modules/strategy/marketRegimeModel.mjs`

| 參數             | 硬編碼值       | 合理性分析 | 建議      |
| ---------------- | -------------- | ---------- | --------- |
| 歷史價格回溯天數 | **126** 天     | ✅ 合理    | 🟢 可保留 |
| 年化週期         | **252** 交易日 | ✅ 合理    | 🟢 可保留 |
| 最小樣本天數     | **60** 天      | ✅ 合理    | 🟢 可保留 |

**詳細分析**：

### `getHistoricalPrices("0050.TW", 126)` ✅ 合理

**合理性**：

- **126 天 ≈ 半年交易日**（252 / 2）
- **足夠的統計樣本**：用於計算 μ 和 σ
- **不過度敏感**：避免短期波動干擾
- **學術標準**：財務學常用半年或一年回溯期

**建議**：🟢 保留，但可提取為常數

```javascript
const REGIME_LOOKBACK_DAYS = 126; // 半年交易日
const prices = await getHistoricalPrices("0050.TW", REGIME_LOOKBACK_DAYS);
```

---

### `periodsPerYear = 252` ✅ 合理

**合理性**：

- **市場標準**：全球股市普遍使用 252 交易日/年
- **台股實際**：台股年均交易日 ~243-245 天，252 是保守估計
- **學術標準**：所有財務學教科書使用 252

**建議**：✅ 保留硬編碼

---

### `minDays = 60` ✅ 合理

**合理性**：

- **統計最小樣本**：計算標準差至少需要 30-60 個樣本
- **避免雜訊**：少於 60 天的數據不足以估計波動率
- **學術標準**：60 天（約 3 個月）是常見的最小回溯期

**建議**：✅ 保留硬編碼
